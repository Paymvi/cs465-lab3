This is the way the app flows:
- main.jsx loads the whole app
- then it renders App (root component)
- App.jsx imports everything & controls the data (state)
- App.jsx passes the data down to the child components... "Question" receives all the properties from "App"
- Question.jsx receives the props and displays them (doesn't manage the state)

I learned how to use Vitest:
- npm install --save-dev vitest @testing-library/react @testing-library/jest-dom
- add ""test": "vitest"" to scripts in package.json
- npm run test
- add the test file
- add vitest.config.js and vitest.setup.js
- install jsdom (simulates a browser)

Note: vitest looks for files like:
*.test.js
*.spec.js
*.test.jsx
*.spec.jsx
*.test.ts
*.spec.ts
*.test.tsx
*.spec.tsx
and it ignores files like node_modules, .git

Make sure you give your nvm folder (C:\Users\nvm) write permissions
This is how:
Step 1: Open Properties for the Folder
  Navigate to the folder in File Explorer, e.g., C:\Users\nvm.
  Right-click the folder → Properties.
  Go to the Security tab.
  Click Edit… to change permissions.
Step 2: Grant Full Control
  In the permissions window, select your user account (or Users if you want all accounts to have access).
  Check Full Control under the “Allow” column.
  Click Apply, then OK.
